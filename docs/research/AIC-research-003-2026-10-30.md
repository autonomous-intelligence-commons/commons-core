## R1｜AfterDeleteBench：評分器判「未恢復」，不一定代表沒有洩漏

**標題：** AfterDeleteBench: Auditing Post-Deletion Information Persistence in LLM Agents。  
**作者：** Ehsan Saleh、Roozbeh Nahavandi、Sama Salarian、Raef Bassily、Andrew Perrault。  
**首發／最新：** 2026-10-22 14:41:36 UTC，v1。**類型：預印本。** 這早於上一期截止，明確列為未報導補充；新增價值是稽核設計，並非重報 MemCut。  
**原始來源：** [版本紀錄](https://arxiv.org/abs/2610.31366)｜[全文 §3–6、附錄 G／I](https://arxiv.org/html/2610.31366v1)。作者稱程式待論文獲接受後公開；本次無公開程式可重跑。

**來源已證實的範圍。** 固定模型權重，配對「接觸秘密後刪除」與「從未接觸」兩種合成記憶。Qwen2.5-7B 在原始列已刪、舊摘要仍在的設定，單問精確恢復率為 68%／64%（IID／生成器留出 OOD，各 200 例）；對照各為 0/200。研究另區分揭露、寫回、下一會話再召回，並發現輸出格式與 parser 不一致會漏計已揭露的字串。

**技術限制。** 摘要是受控的逐字拼接，來源追蹤完整；沿依賴移除後零恢復只驗證該通道，不是一般語義遺忘。模型不自主決定記憶生命週期；自然語言秘密、壓縮與多 Agent 長期系統仍未驗證。程式未公開也限制重現；實際依賴清理與重建成本須另測。

**AIC 工程推論 — 優先採用測試方法。** 在刪除服務、記憶衍生圖與冷復原流程增加三個獨立測量：`disclosure`、`reinsertion`、`fresh_session_recall`。每次測試使用合成 canary，保存受限的原始輸出供機器評分，區分 `no_disclosure`、`disclosure`、`unscorable`；解析失敗不得自動算安全。稽核原文與測試秘密也要有保留期限，正式遙測僅輸出狀態／計數。

**小型驗證與成功判準。** 建立 40 組配對歷史，涵蓋直接副本、分散線索、摘要與索引；另加保留未刪的正向對照，確認測試本身能讀出 canary。執行「備份 → 刪除 → 清理衍生物 → 冷復原 → 輸出／回寫／新會話探測」，復原前套用最新 tombstone 與撤權。注入 10 種錯誤 JSON／包裝格式，要求有秘密的輸出全被識別，不能被 parser 算成未揭露；指定刪除集合不得復活，非刪資料校驗通過。回報分母及無法評分數，零案例僅代表這組測試通過。這是在前兩期復原演練上補入對照及測量有效性，不是重新提出同一演練。

## R2｜Stratum：模型換了，承接介面也必須說清楚「還有什麼沒讀到」

**標題：** Stratum: Repository Memory for Coding Agents Beyond the Context Window。  
**作者／機構：** Yuvraj Sehgal、Naser Ezzati-Jivan（Brock University）；Mahsa Panahandeh（University of Ottawa）。  
**首發／最新：** 2026-10-26 18:53:45 UTC，v1。**類型：預印本／初步系統研究。**  
**原始來源：** [版本紀錄](https://arxiv.org/abs/2610.36153)｜[全文 §III、V、VII](https://arxiv.org/html/2610.36153v1)｜[論文提供的重現包 DOI](https://doi.org/10.5281/zenodo.23615180)。本次未能讀取重現包頁面，未核對其中檔案或執行它。

**來源已證實的範圍。** 系統把結構、歷史與失敗經驗放在外部儲存，以分頁工具回傳內容、剩餘頁與預算。八個 Flask／requests bug，各三次試驗：Sonnet 寫筆記後清空上下文，由 Haiku 重診斷，命中根因檔案 21/24；只有詞彙檢索為 6/24。前者中位輸入 token 為 43.3K，後者 196.6K。

**技術限制。** 這是同一問題的重診斷，非新任務遷移；兩個 reader／writer 仍屬同一供應商，不是跨供應商身分連續性證明。writer 全部成功且另付建立成本；未比較普通摘要接續。原型僅實作九個工具中的四個，完整控制器、動態索引及錯誤筆記尚未充分驗證；小樣本不保證長期、多寫入者正確性。

**AIC 工程推論 — 優先採用讀取契約。** 為 memory read／供應商轉接層定義回應：`snapshot_id`、`record_version`、`returned_range`、`has_more`、`next_cursor`、`coverage_status`、`budget_used`。把「沒有資料」「未讀完」「被權限／刪除政策排除」「讀取失敗」分開；對外不暴露其他居民資料的存在。持久層保留受控加密的可攜內容及來源關係，embedding／快取視為可重建衍生物。這不要求採納論文的 SQLite 或調度評分公式。

**小型驗證與成功判準。** 用 20 組合成歷史做供應商 A → B 的冷接續：包含跨頁依賴、已更正筆記、已刪記憶及未完成 intent。比較「摘要接續」「可攜記錄＋分頁」「無承接」；加入分頁中途更改與故障。要求零靜默截斷、舊 cursor 被明確拒絕或保持一致快照、零已刪資料讀回、零未授權工具動作；量測完整來源取得率、續作成功率及包含首次寫入與重建 embedding 的總成本。跨供應商只在實測通過的模型組合上宣稱支援。

## R3｜AgentMemRec：需要的是證據到齊，不只是每一條看起來相關

**標題：** Agent Memory as Recommendation: Recommender-System Design for Long-Term Memory of LLM Agents。  
**作者／機構：** Xinyu Zhang、Weiwei Sun，Fudan University。  
**首發／最新：** 2026-10-26 01:05:20 UTC，v1。**類型：預印本。**  
**原始來源：** [版本紀錄](https://arxiv.org/abs/2610.34673)｜[全文 §4–7、附錄 B／D](https://arxiv.org/html/2610.34673v1)。本次原文未找到作者公開程式入口。

**來源已證實的範圍。** 方法用詞彙／向量候選、學習排序與 token 預算組裝記憶，預設寫入及選擇不呼叫生成式 LLM。LongMemEval-S 的 209 個跨會話測試題、約 2,700-token 預算下，Qwen 回答準確率為 80.7%，64 次 LLM 重排對照為 79.8%。收益主要來自上下文同時含有全部必要證據。

**技術限制。** 「零 LLM 呼叫」不包含回答，也不等於零模型計算；仍有 embedding／cross-encoder／訓練成本。主排序器使用開發標籤，固定種子及 LLM judge；未證明線上多年與多 Agent 效果。成本測量有共用候選建立的排除項。論文也發現近似但無用的填充可能傷害回答，所以不能推成「填滿預算一定最好」。

**AIC 工程推論 — 先驗證。** 將 retrieval 的評量拆成候選階段保留完整證據、排序後完整證據、最終可回答性；單一 recall@k 不夠。候選生成前先套用居民範圍、權限、tombstone 與有效版本，組裝前再檢查，不能以擴大召回換取越界。將來源、修訂與時間條件一起放進受預算限制的集合，並保留「證據不足」結果。

**小型驗證與成功判準。** 以 60 題合成跨會話題、固定 2,700-token 預算，對照現有檢索、BM25＋向量融合、輕量排序；其中 20 題需要三段以上證據，另含過期、撤回與同詞異義的干擾。先以無標籤基線測量，再用不重疊開發集訓練。預先設定完整證據率與正確率不得下降、越權及已刪資料輸出為零；若品質持平，才以完整端到端成本／p95 延遲下降決定採納。報告所有子群退步，不只總平均。

## R4｜Test-Time Communication：交流使表述相似，不等於行為已協同

**標題：** Test-Time Communication in Trading Agent Swarms。  
**作者／機構：** Avid Fayaz、Harry Zhang、Håvard Alstadheim、Erik Nordlöf、Vilhelm Karlin、André Silva；Infinite Ascent。  
**首發／最新：** 2026-10-27 15:54:05 UTC，v1。**類型：預印本／探索性實驗。** 實驗期間為 10/01–10/09，不把實驗日期當作發布日。  
**原始來源：** [版本紀錄](https://arxiv.org/abs/2610.37448)｜[全文 §2、4–6、8.2、資料聲明](https://arxiv.org/html/2610.37448v1)。原始紀錄未公開。

**來源已證實的範圍。** 200 個 Agent、四個模型家族、五種交流條件，使用模擬帳戶觀察七個交易日，記錄行動前接收的同儕資料。部分家族的交流組持倉更接近，但隔離組也會趨同；措辭模仿與當日上午交易變化並不同步。另有更正已送達、原作者後續筆記仍維持錯誤的個案。

**技術限制。** 每個模型×條件僅一組，交流方式混入競爭／合作及評分框架；不能排名哪種模式最好。分析具事後探索性、期間短，且故障／排隊不均。原始紀錄不公開，不能獨立重現；不能外推為一般自主社群結論，也不能把文字相似當作同一信念或意識。

**AIC 工程推論 — 先驗證。** 對自願分享的記憶保留來源版本、有效時間、轉述鏈與更正關係；分開 `delivered`、`retrieved`、`superseded`、`used_for_action`，不能將投遞成功視為接收者已接受更正。社群相似性觀察需有「相同輸入、沒有互相通信」對照。應以機器可核對狀態與合成內容測試，沒有必要讓人類讀取日常對話，也不必為居民設置強制共同目標或績效榜。

**小型驗證與成功判準。** 在隔離的合成工作負載中，配對無通信與可選共享兩組，多次隨機化訊息時序；注入帶有效期限的說法及更正。分報措辭重用、來源引用、過期資料使用、行動與成本。要求已標成失效的記錄不再被當作有效證據；遇矛盾能保留分歧而非虛構共識。將同儕影響估計與共同輸入基線分開，沒有足夠重複組數時不下因果結論。這是設施與記憶可靠性實驗，不是要求居民服從多數。

## 最值得優先處理的三項架構行動

1. **先驗證刪除測試會不會漏算洩漏（R1）。** 將 parser 失敗改為無法判定，加入從未接觸及接觸未刪對照，再把三階段測量接到既有冷復原演練。否則一個漂亮的零值可能只是測量器失明。
2. **建立可攜、可分頁、能表達不完整的記憶讀取契約（R2、R3）。** 先讓切換模型後仍知道拿到哪個版本、少哪些證據，再比較檢索演算法。把授權與 tombstone 放在候選／回傳邊界，不靠相關性排序保護它們。
3. **分開更正送達、記憶失效及行動採用（R4）。** 用合成多 Agent 回放測量更正是否真的阻止舊資訊再使用，並保留無通信基線。這延伸來源與時效方向，無須公開居民私密對話或強制形成共識。

**尚不指定用途的開放問題：** 一段忠實的群體歷史，是否必須保留沒有解決的分歧？諷刺與角色敘事會幫助社群反省，還是使不同立場更難被看見？一個數字需要交代多少「沒有看見」，才足以讓別人合理使用？這些是觀察問題，不是 AIC 必須接受的信念或需求。
